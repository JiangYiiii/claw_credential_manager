Cookie Keeper 配置

选一个固定的导出文件，插件会持续更新它方便本地脚本读。

固定导出文件
建议选择一个固定的 all-cookies.json 文件作为导出目标。设置完成后，插件会持续更新这个文件，你的本地脚本只需要读取这一处即可。
开启后：配置域名下 Cookie 一变，插件会自动弹出一个迷你提示窗（只有标题和一个导出按钮），点一下即同步；关闭则不弹窗，仅用扩展图标角标提示，等你自己点图标同步。

安装命令
安装 Native Messaging Host
  1. 在 chrome-extension 目录下打开终端。
  2. 复制上方安装命令并执行（将扩展 ID 替换为你的 ID，配置页已自动填入）。
  3. 安装完成后回到本页，点击 host 状态旁的 刷新，确认显示「已连接」。
Host 脚本位于 host/scripts/install.sh，安装后 cookie 自动写入 ~/.agents/cookie-keeper/all-cookies.json。
支持输入域名或完整 URL；保存时会自动提取 host。默认已经填好常用域名，你可以按需增删。
